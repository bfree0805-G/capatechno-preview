業種別の活用

隙間があるところは、すべて測定の対象になります。
航空機の主翼と胴体のすき間から、フィルムを塗る口金、発電機のエアギャップまで。12の業種で、実際に何を測っているかをまとめました。

3種類のセンサー形状

  • A航空宇宙 機体の組立から、エンジンの整備まで。 主翼と胴体の接合部のすき間／リブ（小骨）とスキン（外板）の接合面 ほか 詳しく見る →
  • B自動車 エンジンの内部から、車体のすき間まで。 ターボチャージャーのブレード先端クリアランス／閉鎖面とブロックの間のガスケット圧縮の測定 ほか 詳しく見る →
  • C半導体 高真空・高温の装置の中で、ウェハーの位置を捉える。 シリコンウェハー位置決めシステムの近接管理／ウェハーの変位測定管理 ほか 詳しく見る →
  • Dフィルム・コンバーティング 塗工ダイとロールの隙間が、そのまま製品の品質になる。 スロットダイ（コーティングダイ・口金）のリップ間ギャップ／ローラー間のギャップと、ローラーの振れ ほか 詳しく見る →
  • E複写機・印刷機 ドラムとローラーの位置が、印字の品質を決める。 ドラムの振れ（ランアウト）／ローラーのアライメント（位置合わせ） ほか 詳しく見る →
  • Fコンピュータ周辺・記録装置 重ねたディスクの、一枚一枚の位置を揃える。 多重に積み重ねたディスクパックの一直線上の計測／ディスク駆動機構の内部部品のアライメント調整 ほか 詳しく見る →
  • G電力・発電 タービンの隙間が、発電の効率に直結する。 発電用タービンのブレード先端クリアランス／発電機のロータとステータの間隔 ほか 詳しく見る →
  • H原子力 精度の不足が、そのまま安全上のリスクになる分野。 燃料生産時の燃料ロッド間ギャップの管理／原子力材料の試験 ほか 詳しく見る →
  • I鉄鋼・アルミ・ガラス 高温の製造ラインで、ロールの間隔を見張る。 鋼板の押し出し加工のギャップ設定／アルミニウム板の連続鋳造のロールギャップ監視 ほか 詳しく見る →
  • J材料試験 材料が伸びる・歪む、そのわずかな変化を捉える。 着陸装置のブレーキ支柱のトルク測定用の特別ゲージ／高温用クリップゲージ ほか 詳しく見る →
  • K素粒子物理・研究機関 世界の研究所で、検出器の精度を支える。 検出器の検出部分の均一性の確認・管理／粒子加速器の位置管理 ほか 詳しく見る →
  • L産業機械・モーター 設備の段取りと、モーターのエアギャップ。 工作機械・生産設備の段取り（セットアップ）／設備のアライメント（位置合わせ） ほか 詳しく見る →

NOT LISTED?

載っていない業種・用途でも、ご相談ください。

ここに挙げたのは、製造元の資料と当社へのご相談で実績が確認できた用途です。対象の材質・隙間の寸法・温度・測定箇所までの距離を伺えば、測れるかどうかを先にお答えします。「測れない」場合も、その理由をお伝えします。

  • 材質金属・複合材（CFRP）は非接触で。ゴム・樹脂など電気を通さない面はスプリング接触型で。
  • 寸法寸法の記載があったご相談の62%は1mm以下。薄膜型センサーは厚さ約0.1mm。
  • 温度薄膜型の標準は160℃まで。特注で最大1000℃。
  • 距離測定箇所が奥にある場合は、ワンドの長さ・形状から検討します。
